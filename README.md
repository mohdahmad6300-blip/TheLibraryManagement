\## Library Management System



A console-based Library Management System developed in Java using \*\*OOP concepts, Collections, Scanner, and modular methods\*\*.



The system allows users to:



\* Add and manage books

\* Register library members

\* Issue and return books

\* View all books and their availability

\* View registered members

\* Limit each member to a maximum of 3 borrowed books

\* Take user input through an interactive menu



\### Technologies Used



\* Java

\* OOP (Classes, Objects, Encapsulation)

\* ArrayList

\* Scanner

\* Methods

\* Conditional Statements and Loops



This project demonstrates how Java OOP and Collections can be used to build a simple real-world Library Management System.
